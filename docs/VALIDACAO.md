# Conferencia da entrega

1. Coloque o `db.sqlite3` entregue ao lado de `manage.py` (nao o envie ao GitHub).
2. Instale as dependencias do `requirements.txt` e execute `python manage.py check` e `python manage.py test`.
3. Execute `python manage.py runserver` e acesse `http://127.0.0.1:8000/`.
4. Verifique listagem, detalhe, criacao, edicao, confirmacao de exclusao, 404 em posts inexistentes.
5. Entre com uma conta comum, escreva comentario e veja a ordenacao descendente.
6. Confira 3 categorias, links no menu, exibicao das categorias no detalhe, e listagem por categoria.
7. Teste as cinco consultas SQL do arquivo `docs/sql/consultas.sql` no SQLite.
8. Confira o historico `git log --oneline --graph --all` e `git branch -a`.
9. Faca push no GitHub e publique com `render.yaml`. Insira os dois links no relatorio.
10. Depois da validacao web real, substitua no PDF preliminar as previews por capturas reais das paginas.

Nota: nao usar senhas de teste no ambiente publico.
